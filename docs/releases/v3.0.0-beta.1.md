## GestureKey 3.0.0 beta 1

**Beta:** it works, but some things are still missing and some gestures are being tuned.

The first release of the new GestureKey: a desktop app (Tauri) with a rewritten
recognition engine. Control your PC with hand gestures in front of your webcam.

### Install

Download `GestureKey_3.0.0-beta.1_x64-setup.exe` and run it. It installs for your user
(no administrator needed) and lives in the system tray.

> Windows SmartScreen may warn you because the installer is not signed yet:
> **More info → Run anyway**.

### Gestures

| Gesture | Action |
|---|---|
| ✌️ two fingers, move your hand | Scroll (the page follows your hand; fast goes further) |
| 🤟 three fingers, raise or lower | Volume (back to the same height → same volume) |
| 🤏 pinch, open or close | Zoom |
| ✋ → ✊ and drag | Move windows, across several monitors too |
| …throw it to a side / up / down | Snap / maximize / close |
| ✋✋ bring the palms together | Task view |
| 🖖 four fingers → ✊ | Play / pause |
| ✋ held still, then pushed away | Screenshot |
| ✋✋ both palms still for 1 s | Turn GestureKey on / off |

### What's new

- A new, minimal interface with per-gesture settings and diagnostics.
- Notices at the top of the screen showing what just happened, with a progress ring.
- Steadier recognition: jitter filtering and probabilistic states; gestures end
  cleanly when you lower your hand.
- The camera recovers on its own if it is busy, unplugged or stops sending frames.

### Requirements

64-bit Windows 10/11 and a webcam. To move windows of apps running as administrator,
GestureKey has to run as administrator too.

### Gesture status

- **Tuned:** scroll, volume, on/off, task view.
- **In progress:** moving windows (smoothness and choosing the target monitor), maximize, zoom.
- Mute by gesture is off by default (it will come back with a new gesture).

### Known issues

- In low light the camera drops its frame rate and recognition gets worse; the app warns you.
