## GestureKey 3.0.0 beta 1

**Beta:** funciona, pero todavía faltan cosas y algunos gestos se están afinando.

Primera versión de la nueva GestureKey: app de escritorio (Tauri) con un motor de
reconocimiento reescrito. Controla tu PC con gestos de la mano frente a la webcam.

### Instalar

Descarga `GestureKey_3.0.0-beta.1_x64-setup.exe` y ejecútalo. Se instala para tu usuario
(no pide administrador) y queda en la bandeja del sistema.

> Windows SmartScreen puede avisar porque el instalador aún no está firmado:
> **Más información → Ejecutar de todas formas**.

### Gestos

| Gesto | Acción |
|---|---|
| ✌️ dos dedos y mueve la mano | Desplazar (la página sigue a la mano; rápido llega más lejos) |
| 🤟 tres dedos, sube o baja | Volumen (vuelves a la misma altura → mismo volumen) |
| 🤏 pinza, abre o cierra | Zoom |
| ✋ → ✊ y arrastra | Mover ventanas, también entre varios monitores |
| …lanzarla a un lado / arriba / abajo | Acoplar / maximizar / cerrar |
| ✋✋ juntar las palmas | Vista de tareas |
| 🖖 cuatro dedos → ✊ | Reproducir / pausar |
| ✋ quieta y empujarla | Captura de pantalla |
| ✋✋ palmas quietas 1 s | Encender / apagar GestureKey |

### Novedades

- Interfaz nueva, minimalista, con ajustes por gesto y diagnóstico.
- Avisos en la parte superior de la pantalla con lo que acaba de pasar y un anillo de progreso.
- Reconocimiento más estable: filtrado de jitter y estados con probabilidad; los gestos
  terminan limpio al bajar la mano.
- La cámara se recupera sola si está ocupada, se desconecta o deja de enviar imagen.

### Requisitos

Windows 10/11 de 64 bits y una webcam. Para mover ventanas de apps que corren como
administrador, GestureKey también tiene que correr como administrador.

### Estado de los gestos

- **Afinados:** desplazar, volumen, encender/apagar, vista de tareas.
- **En progreso:** mover ventanas (fluidez y elegir el monitor de destino), maximizar, zoom.
- Silenciar con gesto está apagado por defecto (vuelve con un gesto nuevo).

### Problemas conocidos

- Con poca luz la cámara baja los fps y el reconocimiento empeora; la app lo avisa.
